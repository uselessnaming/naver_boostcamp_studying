# Image 포맷 종류
## PNG (Portable Network Graphics)
이미지의 원래 품질을 유지하며 무손실 압축 포맷을 채택       
ZIP과 동일한 deflate 알고리즘을 사용하여 데이터를 무손실 압축한다.      
다른 무손실 포맷에 비해 압축 효율이 좋기 때문에 사진에서 raw파일을 보관할 때 이미지가 전체적으로 뭉개지는 JPEG나 256색의 한계로 모든 것을 표현할 수 없는 GIF보다 선호된다

**특징**        
- 투명도 지원 : 배경을 투명하게 설정할 수 있어 이미지 위에 겹쳐 자연스럽게 배치 가능
- 뛰어난 화질 : 이미지를 확대하거나 저장할 떄 데이터 손실이 없어 경계선과 텍스트가 선명
- 용량 : 화질이 좋은만큼 용량이 큰 편

## JPG(JPEG)
디지털 사진 및 웹 이미지를 저장하는 데 가장 널리 사용되는 표준 이미지 파일 형식     

**특징**        
- 높은 호환성 : 대부분의 기기, 브라우저, 소프트웨어에서 문제없이 열림
- 효율적인 압축 : 파일 크기가 작아 저장 공간을 적게 차지하고 웹에서 빠르게 전송됨
- 손실 압축 : 용량을 줄이는 과정에서 일부 이미지 데이터가 손실될 수 있기 때문에 그래픽이나 텍스트보다는 사진에 적합

## WebP
구글에서 만든 이미지 포맷이며, 이름처럼 웹 환경을 위해 만들어진 효율적인 이미지 포맷        

구글은 사용량이 많아 사용 트래픽 양이 많은데, 이를 아끼기 위해 이미지 포멧을 최적화 한 것       
> 구글 서비스의 경우 웹 브라우저가 WebP를 지원하면 JPEG 혹은 PNG 대신 WebP를 보내줌

**특징**        
- 압축 방식 : 기존 손실 압축 JPEG / 비손실 압축 PNG, GIF 으로 나눠지지만, WebP는 둘 다 지원해 줌
- 크기 : 손실 압축의 경우 JPEG보다 30% 정도 작음 / 무손실 압축의 경우 PNG 포맷보다 20~30% 정도 작음
- 움직이는 WebP : 움직이는 GIF처럼 WebP 또한 가능
- 제한된 해상도 : 16383 * 16383 pixel 해상도 제한
- 낮은 호환성 : 여러 그래픽 소프트웨어들이 아직 WebP를 지원하지 않고 있다
- 많은 리소스 : WebP를 렌더링하는 과정에서 배터리, 램, CPU 등을 많이 점유, 소비해 효율이 극히 떨어질 수 있음

## SVG (Scalable Vector Graphics)
2차원 벡터 그래픽을 표현하기 위한 XML 기반의 파일 형식

**특징**        
- pixel이 깨지지 않음 : 확대를 해도 픽셀이 깨지지 않음
- 작은 용량 : PNG, JPEG, GIF보다 용량이 작다
- 간단한 이미지 : 단순 도형으로 표현하기 쉬운 이미지 용도로 적합 / 복잡해질수록 CPU 연산량이 늘기에 이미지 로딩이 느려질 수 있고 용량이 커질 수 있음
